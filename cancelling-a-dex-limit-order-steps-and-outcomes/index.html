Cancelling a DEX Limit Order: Steps and Outcomes

To cancel a limit order on a DEX, open active orders, select the order and confirm cancellation. Then check its status and any amount already filled.

Onchain Report NewsroomNov 16, 2026 · 19:53 UTC#e08c713 min read

Open the DEX’s active orders, select the limit order and confirm its cancellation using the method the platform offers. The order must be cancelled through the DEX’s controls, and the cancellation may need a wallet or interface confirmation before the remaining amount stops being available to fill.

A limit order sets the trade terms in advance, which can suit someone who wants to choose a price; a market swap suits someone ready to trade at the available rate. For that first case, see how to choose a KyberSwap limit order. KyberSwap’s order controls also let you cancel a specific active order or cancel all active orders.

How do you cancel a limit order on a DEX?

To cancel one order, open the DEX’s active or open orders list and select its Cancel control. On KyberSwap, choose the active order you want to remove, or use the cancel-all control if you intend to remove every active order.

Review the cancellation method shown before confirming. KyberSwap offers Gasless Cancel and Hard Cancel, but which option is available depends on the order and network. Gasless Cancel follows the gasless confirmation flow shown in the interface. Hard Cancel uses an on-chain transaction, so it requires a wallet confirmation and the network’s gas token. An on-chain transaction must be processed before the cancellation takes effect, so it can take longer to confirm.

Follow the prompt in the DEX or wallet, then check the order’s status or order history. Treat it as cancelled once the interface confirms that status. Note any amount already filled: cancellation stops the remaining amount from being available to fill after it takes effect, while the completed trade stays settled.

Say an order was for two tokens and one has already traded. Cancelling the active order removes the unfilled one-token remainder; it does not undo the token already traded. A completed or expired order is no longer active, so there is no remaining amount to cancel.

Can a limit order fill while a cancellation is pending?

Yes, the order may still fill before the cancellation takes effect. Until the DEX confirms cancellation, the unfilled amount can remain available to fill. This timing matters when the chosen method uses an on-chain transaction, which must be processed. Check the order status after the prompt completes to see whether it was cancelled or filled.

What happens to a partially filled order when you cancel it?

Only its unfilled remainder is cancelled. The amount already traded stays settled, so the result depends on how much filled before the cancellation took effect. A fully filled order has no remainder to remove; a partly filled active order can still have one.

Keep in mind:

  • Cancel from the active orders list and confirm the prompt.
  • Cancellation may require wallet confirmation and gas, depending on the method.
  • For a partly filled order, only the unfilled remainder stops being available to fill.
  • Confirm the final status and note the amount already filled.
