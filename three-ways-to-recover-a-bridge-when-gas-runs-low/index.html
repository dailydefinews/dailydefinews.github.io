Three Ways to Recover a Bridge When Gas Runs Low

When a bridge stalls because gas runs low, first find which step is stuck, then top up, speed up a pending transaction, or use the bridge’s recovery path.

Onchain Report NewsroomOct 16, 2026 · 16:17 UTC#b001253 min read

If a bridge transfer stalls when gas runs low, check which step is stuck before you act. A bridge often starts with a transaction on the source chain, then completes the transfer on the destination chain. Each chain has its own native token for gas, so having enough on one chain does not cover fees on the other. The bridge’s status page or your wallet can help show whether the source transaction is pending, failed, or complete.

What should I check when a bridge transfer stalls?

Check the transaction status on the chain where it was submitted. If it is still pending, the transfer has not yet reached a confirmed source transaction. If it failed or reverted, the bridge may not have received the tokens, though the failed transaction can still use gas. If the source transaction succeeded, look for the bridge’s status or recovery instructions before sending anything again. Bridge fees and chain gas fees are separate costs; how Acrossbridge fees affect USDC is a useful detail when estimating an Ethereum-to-Arbitrum transfer.

Can I speed up a pending bridge transaction?

If your wallet offers a “speed up” option, you can use it to resubmit the same transaction with a higher fee. This is useful when the source-chain network is busy and the original fee is too low. The replacement generally uses the same account nonce, a number that orders transactions from your wallet. Check that the wallet is speeding up the existing bridge transaction, not creating a second transfer. If you do not have enough native tokens to pay the higher fee, you will need to add funds first or wait.

What can I do if the source transaction already succeeded?

First check whether the bridge is still processing the transfer. Some bridges use a relayer, a service that submits the destination transaction, so you may not need to pay destination gas yourself. Others may require you to claim or retry the transfer. Follow the bridge’s own status and recovery steps, and keep enough of the destination chain’s native token available if it asks you to submit a transaction.

Which recovery option should I try first?

Match the fix to the transaction state. A new transfer is rarely the right first move: it can create a second payment while the original is still being processed.

  • Pending on the source chain: Use your wallet’s speed-up feature if you can afford the higher gas fee; otherwise wait or add the chain’s native token.
  • Failed on the source chain: Confirm the failure in a block explorer, then retry only after checking the token amount and fee balance.
  • Source confirmed, destination incomplete: Check the bridge’s status and use its claim, retry, or support route if offered.

Only use recovery links from the bridge’s official site or app. Never share your recovery phrase to get help. For most readers, the safest and cheapest first step is to identify the stuck stage, then pay only the fee needed to move that stage forward.
