DEX Swap Route Hops: How Pools Pass Tokens

What does each hop in a DEX swap route mean? Each hop is one liquidity-pool swap, passing its output token to the next pool until the route reaches your chosen token.

Onchain Report NewsroomNov 18, 2026 · 06:54 UTC#d973403 min read

Each hop in a SunSwap route is one swap through a liquidity pool, moving from one token to the next until the route reaches the token you want. For a new TRON trader, the route shows how the starting token becomes the final one.

  • Each arrow connects two tokens; the hop between them is one pool swap.
  • In A→B→C, one pool swaps A for B, and another swaps B for C.
  • The pools’ prices and fees contribute to the route’s quoted output.

A route can include a middle token when there is no direct pool between the tokens you chose, or when another path gives a better quote. For more on SunSwap routing around missing direct pools, see how SunSwap can use an intermediate token to connect a swap.

Each arrow marks a pool swap

A route is a chain of token swaps, with each hop handled by one liquidity pool. TRC-20 tokens can be swapped through pools on TRON. Read the route from left to right: the first token is the input, and the last token is the output.

Say the route shown is A→B→C. The first pool takes A and returns B. The next pool takes that B and returns C. That is a two-hop route because it uses two pools. B is the intermediate token: it connects the two swaps.

Imagine you want C and the quote shows A→C before you trade. In this illustrative case, the route has no direct A-to-C pool, so the quoted path is A→B→C. Your goal stays the same—you still want C, and A is still your starting token. What changes is the path: the first pool outputs B, which becomes the second pool’s input.

Intermediate tokens pass between pools

The route passes each pool’s output to the next hop automatically. You generally need to hold the starting token, A, rather than A, B, and C. B appears in the route because the pools use it to connect the swaps; it is not an extra token you have to acquire and send yourself.

Each hop contributes its pool price and fee to the final quoted output. The amount of C shown in a quote reflects the full route, so a second hop adds another pool’s pricing and fee to the calculation. A different route can give a different quote because it uses different pools.

Why does a swap route use multiple hops?

A route uses multiple hops when a direct pool is unavailable or another path gives a better quote. An intermediate token lets two pools connect the starting token to the one you want.

Do I need to hold the middle token in a route?

Generally, no. The pools pass the intermediate token along automatically. Follow the arrows to count the pool swaps, then compare the quoted output for the route before deciding whether to trade.
