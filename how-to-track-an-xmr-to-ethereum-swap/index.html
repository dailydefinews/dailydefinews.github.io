How to Track an XMR-to-Ethereum Swap

An XMR-to-Ethereum swap can pause at several checkpoints. Learn how to tell whether Monero, the swap service or Ethereum is holding it up.

Onchain Report NewsroomOct 3, 2026#cff1373 min read

An XMR-to-Ethereum swap moves through separate Monero, service and Ethereum steps, so a delay at one stage does not tell you what happened at the others. Start with the order page or receipt, which should show the deposit amount, destination and any time limit. Swap routes work in different ways; for a route-by-route comparison, see this guide to XMR bridge routes and when to use each. Keep the order ID and any transaction IDs together as you check progress.

How do you check whether Monero arrived?

Check the swap service’s order page first to see if it has detected your deposit. Then check the transaction in your Monero wallet. A Monero transaction ID, or txid, identifies the transaction, but Monero’s privacy design means a public explorer may not show the same details you would see for an Ethereum transaction. Your wallet can show whether the transaction is still pending or has been included in a block. The service may also need to wait for its own required number of confirmations before it accepts the deposit.

If the wallet says the transaction is pending, it has reached the network but has not yet been included in a block. If it shows as confirmed but the order page has not moved, the service may still be waiting for enough confirmations or for its deposit check to finish. Compare the amount and destination with the order details. If you contact support, share the order ID and the Monero txid through the service’s official support channel.

What happens after the deposit is confirmed?

Once the service recognizes the deposit, it must carry out the exchange before Ethereum can show a payout. The exact steps depend on the route. A service may handle the exchange itself, or a bridge may use a contract and a token that represents an asset on another network. Either way, a confirmed Monero deposit does not by itself prove that ETH has been sent.

The order page may show a processing or exchange stage while this work happens. Look for a separate Ethereum transaction hash when the payout is sent. That hash is the identifier you can use to check the transaction in an Ethereum block explorer. Until a hash appears, the payout may not yet have been broadcast to Ethereum.

How can you tell if ETH has reached your wallet?

Check the Ethereum transaction hash for its status and destination address. A pending transaction has been broadcast but is not yet included in a block. A successful transaction has been included; a failed one did not complete as intended. Confirm that the destination address matches your wallet. Also check that you are viewing the same Ethereum network used by the swap route.

Use each checkpoint to narrow down where the wait is:

  • No Monero txid in your wallet: Check the wallet’s send history and whether the transaction was submitted.
  • Monero is pending: Wait for it to be included in a block, then check whether the swap service has detected it.
  • Deposit confirmed, no Ethereum hash: Check the order page for processing updates and any stated time limit.
  • Ethereum hash is available: Check its status and recipient address on the correct network.

Don’t send a second deposit just because an order appears stuck. First check the order status, transaction details and any deadline or minimum amount shown when you started. If a stated time limit has passed, contact the service with the order ID and relevant transaction IDs; never share wallet seed words or private keys.
