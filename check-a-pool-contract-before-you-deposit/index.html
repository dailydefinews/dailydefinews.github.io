Check a Pool Contract Before You Deposit

Before adding money to a liquidity pool, match the contract to a trusted source, check its tokens and chain, and review what your wallet is being asked to approve.

Onchain Report NewsroomOct 27, 2026 · 18:49 UTC#872e103 min read

Before depositing into a liquidity pool, confirm that the contract address belongs to the pool you mean to use. A pool contract is the on-chain program that holds or manages the tokens you supply. A lookalike pool can use the same token names and logo, so check the address and network, not just the page design.

Where can you find the right pool address?

Get the address from a source you already trust, such as the exchange’s official app or its documentation. Check that the app itself is genuine, then open the pool details and copy the contract address. A search result, social post or message from someone you do not know is not a reliable source. For a worked example of pool checks, the sushiswap guide covers details you can compare before trading or adding liquidity.

Next, open the address on the block explorer for the same network. A block explorer is a public site for viewing on-chain activity. Confirm the address matches exactly, including every character. Also check the network: the same token or pool name can appear on several chains, but each has separate contracts.

What should you check on the contract page?

Check the token addresses listed for the pool, not only their names or symbols. Anyone can create a token with a familiar name. Compare each address with a trusted source for that token. Then check that the pool type and fee match the option you selected. Some pools use a fixed price range; others let liquidity providers choose a range. Those designs can affect how and when your funds are used.

Look for a verified contract on the explorer. This means the published code has been matched to the code running on-chain, which helps people inspect what it does. Verification is useful, but it does not prove the contract is safe or that it is the official pool. The address still needs to match a trusted source.

  • Confirm the network shown in your wallet and on the explorer.
  • Match the pool and token contract addresses against trusted details.
  • Check the pool type and fee before connecting your wallet.
  • Read the wallet prompt and confirm which tokens and permissions it requests.

What should you review before approving a deposit?

Read the wallet screen before signing. A token approval lets a contract spend up to a stated amount of that token. Check the token and spender address, and avoid approving an unlimited amount if the wallet offers a smaller option. A deposit may require a separate transaction after approval, so review that prompt too.

These checks reduce the chance of sending funds to the wrong pool, but they cannot remove market risk. Pool tokens can change in value, and fees may not make up for that change. For most readers, the practical rule is simple: verify the address from a trusted source, check the wallet request, and skip the deposit if either one does not match.
