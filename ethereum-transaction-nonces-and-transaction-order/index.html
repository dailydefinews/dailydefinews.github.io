Ethereum transaction nonces and transaction order

A transaction nonce in Ethereum is an account’s next number in sequence. Learn how it orders transactions, blocks later sends and helps replace a stuck one.

Onchain Report NewsroomNov 27, 2026 · 23:24 UTC#1091263 min read

A transaction nonce in Ethereum is an account’s next number in sequence, and each transaction must use that number to execute in order.

Think of it like numbered tickets: ticket 8 must be handled before ticket 9. An externally owned account (a wallet controlled by a person) starts at nonce 0. Each executed transaction adds 1. The nonce is not a fee or a balance; the Ethereum Yellow Paper defines it as a count tied to the sending account.

What does an Ethereum nonce count, and why can it hold up later transactions?

An account nonce counts transactions sent from that account and sets their execution order. Etherscan shows the nonce on each transaction page. Under EIP-161, a contract’s nonce starts at 1 and counts contracts it creates, so a contract account’s nonce has a different role.

Say your wallet has a transaction at nonce 8 waiting because its fee is too low. A later transaction at nonce 9 cannot execute first, even if you offer a higher fee for it. The pending transaction holds up every later one from that address until nonce 8 is confirmed or replaced.

This can happen when you approve a token before making a deposit. A Base bridge is a cross-chain service for moving supported crypto assets between Ethereum and Base. In that flow, a stuck approval at nonce N blocks the deposit at N+1 until the approval confirms or you replace it; the Base bridge is one example of where that order matters.

Each chain tracks its own nonce. The same address can have one count on Ethereum and a separate count on Base. A transaction on one chain does not advance the other chain’s counter.

How do same-nonce replacements speed up or cancel a transaction?

A replacement uses the same nonce as the pending transaction and raises its fee enough for the node to accept it. “Speed up” and “cancel” both work this way: the wallet sends another transaction at the blocked nonce with higher fees. A cancellation is still a transaction; if it is accepted, it takes that nonce’s place.

Geth’s default price bump is 10%. For an EIP-1559 transaction, raise both maxFeePerGas and maxPriorityFeePerGas by at least 10%. If both rise by that amount, Geth accepts the replacement under its default rule. If maxFeePerGas rises by 10% but maxPriorityFeePerGas stays the same, Geth rejects it as “replacement transaction underpriced.” The deciding factor is whether both fee fields meet the bump.

What does a “nonce too low” error mean?

It means the transaction’s nonce is below the account’s current nonce on that chain, often because a transaction with that number already executed. Check the account’s latest transactions on the right network before retrying.

How do I reset the nonce in MetaMask?

You cannot reset the on-chain counter in MetaMask. Its “clear activity and nonce data” option clears MetaMask’s local transaction history; it does not change the chain’s nonce or remove a pending transaction. For a stuck send, use speed up or cancel with the same nonce. Before sending anything else, compare the wallet’s pending nonce with the latest confirmed nonce to avoid adding another transaction behind the blockage.
