How to Track a Solana Token Creator Wallet Through Its History

Learn how to track a Solana token creator wallet: find the exact mint, inspect its creation transaction, compare wallet roles and review on-chain history.

Onchain Report NewsroomNov 28, 2026 · 07:09 UTC#52e91d3 min read

To track a Solana token creator wallet, start with the exact mint address, inspect its creation transaction in Solscan, then follow the fee payer and mint authority separately.

Say a hypothetical token called Cedar appears in a project post. At first, you have only its name and ticker, which another token could copy. Copy Cedar’s exact mint address from the project’s official channel. The mint address identifies the token’s mint account, the on-chain account that holds its settings.

A rugcheck is a review for warning signs that could point to a scam or rug pull, and wallet activity can add useful context. For more on how rug pulls work through three exit levers, read our article on Solana rug pulls’ three exit levers.

Follow the mint’s creation transaction and wallet roles

Solscan can show Cedar’s creation transaction and the wallet roles recorded there. Open the mint address, locate the transaction that created the token, and inspect its signers and fee payer. Signers approve a transaction; the fee payer covers its transaction fee. These roles can belong to different wallets.

Then inspect the mint authority field. The token mint account records its mint authority, which can create more tokens. That authority can be changed or revoked. Compare it with the fee payer before calling either wallet the creator or controller. One paid for the transaction; the other has a token-specific role.

For the illustrative Cedar case, open the fee payer’s address in Solscan and review its earlier activity. Look for other token launches, how the wallet received funds, and what it did after Cedar’s creation. Repeat the review for the mint authority if it is a different wallet. The transaction view has now led to a broader history, while Cedar’s mint address and recorded transaction remain the same.

Follow transfers among those wallets, Cedar’s top holders, and its liquidity pool. Note when tokens move and where they go. A transfer can show a connection or change in holdings, but the transfer alone does not establish why it happened. Keep the addresses and transaction links you want to monitor.

This wallet trail gives a token risk review more on-chain context, but it may not reveal every person involved. A creator can use several wallets or transfer control. Compare the history with other token risk signals before drawing a conclusion; a rugcheck is stronger when it considers the token as well as the wallets around it.
