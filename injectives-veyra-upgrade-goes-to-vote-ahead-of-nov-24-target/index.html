Injective’s Veyra upgrade goes to vote ahead of Nov. 24 target

Injective's IIP-717 vote would move the chain to v1.21.0 on Nov. 24 and add cross-chain asset routes and institutional trading tools if stakers approve it.

Onchain Report NewsroomNov 13, 2026 · 11:57 UTC#f0af0e2 min read

Injective’s Veyra mainnet upgrade is up for a governance vote, with activation targeted for November 24 if the proposal passes. The change would add tools for moving assets across networks and trading tokenized assets.

The Injective Chain upgrades page lists proposal #717 as voting and sets the planned halt at block 193,145,000. The proposal record says the vote runs from November 12 to November 16. If approved, the chain would halt at that block and resume on version 1.21.0. The date is a target tied to the block height, not a guaranteed launch time.

Veyra’s proposal describes changes to Injective’s MultiVM setup, which supports applications built for different virtual machine environments. It would add IBC routes, a cross-chain messaging system, to let assets move between Injective’s Ethereum Virtual Machine environment and other connected chains.

For trading, the proposal adds request-for-quote infrastructure, where a trader asks liquidity providers for prices before placing a trade, and expands atomic swaps, which are exchanges designed to complete together or fail together. The proposal says these features are intended to support institutional trading and settlement for tokenized assets.

The proposal also says Veyra would prepare technical foundations for CypherOS, Injective’s planned privacy platform. CypherOS is not part of this vote as a launched product: the proposal describes it as upcoming work intended to support confidential trading and financial transactions.

The vote is a step before any network change takes effect. Injective’s upgrade page explains that major software versions are activated through governance proposals. If this one passes, validators would switch to the new software when the chain halts at the specified block. The proposal does not set a clock time for that halt.

The proposal presents Veyra as an infrastructure update for asset issuance, cross-chain liquidity, trading and settlement. Its stated goal is to support more tokenized financial products on Injective. Whether those tools lead to new products or trading activity will depend on their later use by issuers, institutions and developers.
