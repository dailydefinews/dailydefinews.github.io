Aztec’s Tierra V6 upgrade speeds up private apps

Aztec's Tierra V6 upgrade roughly doubles private proof speed and speeds Ethereum deposits, while fixing a critical flaw in the network's earlier version.

Onchain Report NewsroomNov 4, 2026 · 08:18 UTC#dee06c2 min read

Aztec released Tierra, its Alpha V6 network upgrade, on Nov. 3, saying it roughly doubles private transaction proof speed and fixes a critical flaw in the previous version. The changes aim to make private apps quicker to use on this Ethereum Layer 2, a network built on top of Ethereum. In its Tierra launch announcement, Aztec said proofs can now be made in about one second on a user’s device, while messages from Ethereum reach Aztec in as little as 12 seconds.

How does Tierra make private transactions faster?

Aztec says private transaction proofs now take about one second on a native device, twice as fast as on the previous network. A proof is a way to show that a transaction is valid without revealing its private details. Aztec says those proofs are created on the user’s device.

The upgrade also changes how messages travel from Ethereum to Aztec. Delivery previously took an average of two minutes; it can now take as little as 12 seconds, according to the announcement. That can speed up deposits and other activity between the two networks.

What security issue did the upgrade fix?

Tierra resolves a critical vulnerability in the V5 proving system, which Aztec contributors disclosed in August. Aztec’s network status page says the flaw is fully resolved in V6. The page lists Tierra as an Alpha release and says no security incidents have been reported for it.

The upgrade also adds an AI-powered security testing system and formal verification of core cryptographic components, according to Aztec. Formal verification uses mathematical methods to check that parts of a system meet specified rules.

Which apps are coming to Aztec?

Aztec says apps launching or preparing to deploy include zk.money for private payments and savings, Nyx for private payments to Ethereum wallets, and Galactica for private AI services. The announcement names zk.money and Nyx as leading apps for the upgrade. It does not say that every listed app is already live.

Aztec describes its network as a decentralized Ethereum Layer 2 with more than 3,000 validators. Tierra is still an Alpha release, so it remains an early version of the network. The upgrade pairs faster proofs and Ethereum deposits with a fix for the V5 flaw, as Aztec builds out its private app ecosystem.
